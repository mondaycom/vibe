# StrokeSpotlight

A pointer-following conic stroke and glow that wraps chat composers and similar surfaces. Move the pointer near the box to travel the highlight; click to pulse; focus inside to suppress the traveling stroke.

## Overview

Move your pointer around the composer to see the stroke follow. Click the surface for a one-shot pulse. Focus the textarea to pause the traveling stroke.

<Canvas of={StrokeSpotlightStories.Overview} />

## Import path

```tsx
import { StrokeSpotlight, STROKE_NO_PULSE_ATTR } from "@vibe/core";
```
