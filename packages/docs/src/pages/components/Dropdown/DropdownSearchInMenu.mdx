# Dropdown search in menu

A searchable dropdown whose search field is rendered at the top of the opened menu instead of in the trigger. The trigger keeps showing the selected value (or placeholder), so the field looks the same as a regular dropdown until it's opened. Enable it with <code>searchable</code> and <code>searchPlacement="menu"</code>.

<Canvas of={DropdownSearchInMenuStories.Overview} />

## Variants

### Single and multi select

Multi select keeps the menu open between selections and shows the selected items as chips in the trigger.

### Sizes

The search field matches the dropdown size: small (32px), medium (40px) and large (48px).
