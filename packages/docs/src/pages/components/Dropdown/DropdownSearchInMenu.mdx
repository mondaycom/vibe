# Dropdown search in menu

A searchable dropdown whose search field is rendered at the top of the opened menu instead of in the trigger. The trigger keeps showing the selected value (or placeholder), so the field looks the same as a regular dropdown until it's opened. Enable it with <code>searchable</code> and <code>searchPlacement="menu"</code>.

<Canvas of={DropdownSearchInMenuStories.Overview} />

## Accessibility

<UsageGuidelines
  guidelines={[
    <>
      The trigger is a button (<code>aria-haspopup="listbox"</code>). It opens with click, <code>Enter</code>,{" "}

    <>
      Opening the menu moves focus to the search field. Arrow keys move through the options and <code>Enter</code>{" "}

    </>,
    <>
      <code>Escape</code> or selecting an option closes the menu and returns focus to the trigger. <code>Tab</code> and{" "}

    </>,
    <>
      The search field is named by <code>inputAriaLabel</code>, falling back to <code>label</code> and then{" "}
